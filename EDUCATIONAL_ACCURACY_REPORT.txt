A. CURRENT ARCHITECTURE

The chat handler retains authentication, session ownership, board/class/subject
checks, request admission, replay handling and credit settlement. It then resolves
the student's reference before retrieving an exact answer:

  Question + student history -> reference type/scope -> curriculum-constrained
  source lookup -> reviewed source/meaning rendering OR honest fallback.

Canonical numbers, textbook selection ordinals, chapter, lesson, exercise,
question and page numbers have distinct identities. Exercise/question compound
references retain their parent qualifier. Ambiguous numbers prompt clarification.
Explicit canonical intent is required before using a numbered canonical Kural.

Textbook records must match board, class, subject, reference and supplied scope,
have verified status, source title/URL, edition, content version and content.
Multiple matching editions/items fail closed. A user hint may narrow existing
reviewed metadata; it cannot mark a record verified. No missing textbook item
is replaced by a canonical item with the same number.

Source passages, source meanings, reviewed simplifications and teaching examples
are separately labelled. Missing reviewed explanations/examples are disclosed.
Canonical Kural replies use historical commentary only when safely paired with
the exact verse. Otherwise the verified verse is shown with an explicit notice
that its explanation has not been verified. No nearby-number meaning is borrowed.

Other conceptual questions continue through board/class/subject-filtered RAG and
the existing model. Generated answers are buffered before display. Conservative
guards reject unsupported quoted strings, generated citations/page claims and
some explicit numeric/scientific contradictions. This is not comprehensive
semantic verification of every generated explanation. Cached answers pass the
same guard. Retrieval failures do not establish textbook coverage or absence.

D. EXPLANATION VALIDATION

The exact textbook path does not ask the model to improvise an interpretation.
It displays only reviewed meanings/simplifications. The meaning-preservation
check accepts normalized approved text, not keyword overlap or model agreement.
The regression fixture rejects the supplied wrong interpretation about wealth
and accepts the reviewed selfishness/selflessness explanation.

This is a deliberately conservative baseline: it can reject valid new
paraphrases and cannot independently prove that an editor's approved meaning is
correct. Production review is essential. Generic generated lessons, image
interpretations, grammar, units, scientific processes and historical reasoning
do not yet have comprehensive subject-level semantic validators.

The common reviewed-source path works for Tamil, Mathematics, Science, English
and Social Science in fixture tests. Deterministic arithmetic uses bounded AST
evaluation and exact rational numbers. Additional checks cover plain numeric
equalities and a narrow water-formula assertion. The small curated fact collection
is not complete syllabus coverage. Algebra, dimensional analysis and arbitrary
science/history/grammar correctness remain outside this validation baseline.

E. CONTEXTUAL REFERENCE RESOLUTION

1. Textbook scope + reviewed test selection 7 -> thirukkural:72.
2. Explicit original/canonical Kural 7 -> canonical verse 7.
3. Bare 7 or unqualified Kural 7 without scope -> one clarification.
4. Missing/unreviewed/ambiguous textbook mapping -> honest unavailable answer.
5. Meaning, simpler explanation, example, why and next-item follow-ups retain
   reference intent. “No” acknowledges the student instead of repeating a verse.
6. Subject/grade/board lookup filters prevent fixture cross-curriculum retrieval;
   existing session mismatch checks are retained.

The user requested academic year 2026–27. The current official SCERT catalogue
links to a State Board Class 6 Tamil Term I PDF whose edition page says 2024
reprint. Visual review establishes selection 7 on printed page 49 (PDF page 57),
with the supplied verse and meaning; canonical 72 agrees with the preserved
canonical corpus. The separately catalogued CBSE Tamil reader has the same item
on printed page 49 (PDF page 59), also in a 2024 reprint. Board identities are not
merged. This establishes the mapping in those editions, NOT 2026–27 applicability.

Only exact source text and source meaning were added. No generated simplification
or example was marked reviewed. Following the user's approval, 2024 is the default
for reviewed Class 6 Tamil textbook Kural selections in TN and CBSE, with separate
board identities. A request for 2026–27, another edition or another term cannot
fall back to them. Other grades/subjects receive no inferred edition. Whole-page requests
cannot return the one selected excerpt as if it represented the full page.

Server-only memory now retains the resolved reference plus actual source
edition/year/term for 30 days. It is constrained to the same user, session, board,
class and subject. New topics clear item identity; parent-reference changes clear
stale exercise/page qualifiers. The server rechecks the source before responding.
When the migration is absent, normal history-based resolution remains available;
no persistence claim is made for the unchanged production database.
